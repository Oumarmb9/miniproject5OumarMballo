About BookNook

BookNook is a small Flask web application built for INF601 – Advanced Programming in Python (Mini Project 5). It demonstrates a complete, database-backed web app with user accounts.

What it does

  • Lets you create an account and log in securely (passwords are hashed, never stored in plain text).
  • Gives each user a private bookshelf stored in a SQLite database.
  • Supports adding, editing, viewing, and deleting books with a title, author, status, rating, and notes.

How it's built

  • Flask — routing and the application-factory pattern.
  • Python's built-in sqlite3 — the SQLite database, with two tables linked by a foreign key.
  • Flask sessions + Werkzeug — the register / login system with hashed passwords.
  • Bootstrap 5 — responsive styling and the delete-confirmation modal.
